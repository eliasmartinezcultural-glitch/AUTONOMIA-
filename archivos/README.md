# Archivos descargables

Guardá aquí los materiales que se publiquen en la biblioteca, organizados en subcarpetas como `libros/`, `documentos/`, `educacion/` y `guias/`.

Antes de subir un archivo, verificá que sea propio, de dominio público o que exista permiso/licencia para compartirlo. Después agregá su ficha en `../catalogo.json`.
